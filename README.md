# Credit Lens

**Tu crédito, claro.** Demo de un centro de crédito personal para Colombia: puntaje explicado, simulador, plan para salir de deudas, permanencia de reportes negativos (Ley 2157 de 2021) y carta de derecho de petición en PDF.

> Demo con **datos ficticios**. No está afiliado a DataCrédito, Experian, TransUnion ni a ninguna central de riesgo. No es asesoría legal ni financiera.
